# Практическая работа №10 — ML-продукт для анализа отзывов

Ершов Н.С., группа П-3-23, дисциплина «Технология разработки и защиты баз данных».

Базовый код лекции (генерация датасета из 200 отзывов, маскирование персональных данных, классификация тональности,
прогноз количества отзывов, рекомендации) дополнен функциями:

- `predict_sentiment(text, vectorizer, model)` — возвращает «позитивный»/«негативный» и % уверенности;
- `top_products_by_positive(df, n)` — топ товаров по доле позитивных отзывов;
- `top_negative_words(df, n)` — 5 самых частых слов в негативных отзывах;
- `build_report(...)` — вся статистика и графики сохраняются в `student_report.png`.

## Запуск

```
pip install -r requirements.txt
python review_analyzer.py
python -m pytest
```

Файлы: `review_analyzer.py` — код, `reviews.csv` — датасет, `student_report.png` — итоговый отчёт, `test_analyzer.py` — тесты.
